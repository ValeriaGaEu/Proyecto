# HYDROFARM 🌱

HydroFarm es un sistema inteligente de gestión para un huerto hidropónico, desarrollado con el objetivo de facilitar el monitoreo, 
administración y control de un sistema de cultivo mediante herramientas tecnológicas. Este proyecto fue creado en Java e integra una base 
de datos para almacenar y gestionar información importante sobre usuarios, plantas, sistemas hidropónicos, soluciones nutritivas y registros 
de monitoreo.

El propósito principal de este proyecto es ofrecer una solución organizada para administrar un huerto hidropónico, permitiendo a los
usuarios llevar un control más eficiente del proceso de cultivo. El sistema permite registrar plantas, gestionar los componentes del
huerto, almacenar información sobre las soluciones nutritivas y consultar datos relacionados con las condiciones del cultivo.

La aplicación cuenta con diferentes módulos para la administración del sistema, incluyendo gestión de usuarios, registro de plantas, control 
del sistema hidropónico, monitoreo de parámetros ambientales y manejo de soluciones nutritivas. Mediante una interfaz gráfica desarrollada con
Java Swing, los usuarios pueden interactuar con el programa de una manera sencilla, realizando acciones como registrar, modificar, eliminar y 
consultar información.

Este proyecto busca apoyar el uso de la agricultura sostenible mediante la implementación de tecnologías que ayuden a optimizar recursos como el 
agua y mejorar el control de los cultivos. Los sistemas hidropónicos permiten producir alimentos utilizando métodos más eficientes, por lo que 
esta aplicación representa una combinación entre desarrollo de software y soluciones innovadoras para la agricultura moderna.

### Tecnologías utilizadas:

* Java
* Java Swing (Interfaz gráfica)
* MySQL (Base de datos)
* JDBC (Conexión con base de datos)
* Programación Orientada a Objetos (POO)
* Patrón de diseño DAO

Hydroponic Garden representa la integración de la tecnología y la agricultura sostenible, creando una herramienta que permite administrar un 
huerto hidropónico inteligente y demostrar cómo el desarrollo de software puede contribuir a mejorar los procesos agrícolas.
